Beldex testnet setup
  1. Install the official Chrome Beldex extension and save its 25-word recovery seed offline.
  2. Switch the extension to Testnet and check network badge.
  3. Request test BDX from the faucet. Registration consumes 200 test BDX plus network fees.
  4. Register a test Privacy Token: name Veil Receipt, ticker VEIL, decimals 9, initial supply 5000, maximum 100000.
  5. Approve registration in your own wallet, and save the Privacy Token ID and hash.
  6. Record test transfers with honest evidence; do not send seeds, private keys or view keys to this app.
