## Description ready to paste
VEIL//RECEIPT is an open-source, noncustodial merchant invoicing and private-payment receipt toolkit for Beldex. Our working prototype provides an accessible merchant dashboard, operator-reviewed transaction references, Ed25519-signed statements with tamper detection, and a tested wallet-connection/balance interface via Beldex's official @bdxi/web3js SDK. Six automated tests currently pass. We explicitly distinguish operator statements from genuine blockchain payment proofs: the official wallet must be installed for user-approved testnet actions, and independent Privacy Token payment-proof APIs have not yet been confirmed. We propose milestone-based work on actual Beldex Proto Privacy Token registration, testnet checkout, a narrowly scoped receiver-authorized verification standard, security hardening, and developer documentation. Detailed milestones and a proposed US$30,000 budget are in docs/GRANT-PROPOSAL.md. Public source: https://github.com/enstest1/veil-receipt . We are applying with a functioning prototype, not claiming a production payment processor.
